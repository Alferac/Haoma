# Обновление заметки Obsidian

Обнови заметку в базе знаний Obsidian новой информацией из видео.

Текущее содержимое заметки:
{current_content}

Новая информация из видео:
- Источник: [{video_title}]({url})
- Канал: {channel}
- Дата: {date}
- Роль в видео: {role_in_video}
- Что узнали: {what_learned}

Правила обновления:
1. Добавь запись в секцию "## Заметки из источников":
   - [{video_title}]({url}) ({date}): {what_learned}
2. Обнови поле `updated` в frontmatter на {date}.
3. Если новая информация существенно дополняет поля frontmatter (maturity, cost, ai_relevance, suitable_for, project_stage, team_size) — обнови их.
4. Если появились новые ключевые возможности — добавь в соответствующую секцию тела.
5. Всё остальное оставь без изменений.
6. Верни ПОЛНОЕ содержимое обновлённой заметки, без пояснений.
